THE CENTREPIECE. Rehearse on the laptop you present from. Linux host: all three match. macOS / Windows (Docker Desktop): the host does NOT match — it prints Darwin or a Windows version, the containers print Linux (often linuxkit/microsoft). SAY WHY OUT LOUD: Docker Desktop runs containers inside a small Linux VM, and the shared kernel is THAT VM's. This is not a failed demo — it shows both of today's boundaries at once, and half the room will see exactly this in Lab 1.
